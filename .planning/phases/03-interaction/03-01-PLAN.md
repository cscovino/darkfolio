Design decisions documented by the planner (discretion per 03-CONTEXT.md):
- **Registry shape supersedes PLAN.md §Phase 3's per-object classes** (Interactable.ts/Computer.ts/…): CONTEXT D-03 + its discretion section name the Phase 2 `DOORS` data-registry precedent, and 03-PATTERNS.md prescribes `interactables.ts` + one generic loop. Data entries, not classes; no Bed object exists (D-03 locks five interactables).
- **Overlay content is build-time embedded, not runtime-fetched**: GameOverlay.astro renders the shared ContentList into hidden per-page slots at build time; the open event reveals the matching slot. This satisfies the UI-SPEC truth (content present at open, no in-flight state) with zero fetch machinery — the shared component is the Phase 6 seam per UI-SPEC §Phase 6 Handoff.
- **Phaser↔DOM bridge = a window CustomEvent pair** (`darkfolio:overlay` scene→DOM with `{ page, statusLine }`; `darkfolio:overlay-close` DOM→scene), flagged by 03-PATTERNS.md as the no-analog design decision. The scene owns all timing (250ms/200ms overlay slide durations mirror the CSS durations via delayedCall).
- **Scope note — the single tracer task lists 11 files, over the 10-file warning threshold, by design.** The tracer-first contract requires ONE slice that wires every layer the phase touches end-to-end (pure geometry module → scene state machine → zoom-1 canvas UI → Phaser↔DOM bridge → Astro route); splitting page-route creation from the scene/UI wiring would ship half a path that cannot run, defeating the tracer's purpose. The estimate (raw 42k × 2 = 84k tokens) stays inside the per-plan budget, and none of the three legitimate split triggers applies: context cost, missing information, and dependency conflict are all absent.

Flagged assumptions (specless edge probe returned these requirements unclassified — never auto-resolved; recorded, not silently dropped):
- **INTR-01**: pressing E with no interactable in range is silently ignored (no "nothing here" feedback); reach boundary is inclusive — a gap of exactly 32px counts as in range.
- **INTR-02**: dialog copy is author-controlled and capped at 120 chars by the UI-SPEC copy contract; no runtime truncation is implemented for over-long strings.
- **INTR-03**: a host object's content slot is always present in the DOM (build-time embed); no loading or fetch-failure path exists for the happy path.
- **INTR-04**: OS key auto-repeat is neutralized by Phaser `JustDown` edge detection in the scene and a single keydown handler on the panel; a held key does not re-fire.
- **INTR-05**: (deferred to Plan 02) counter wraparound is modulo; state is in-memory per D-20 — cross-reload persistence is v2 PERS-01, not this phase.
